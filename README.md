# 🎮 Soc Ops – The Social Bingo Game

> **Break the ice, find your people, get 5 in a row!**  
> A fun, interactive bingo game designed for in-person mixers, conferences, and community events. Match questions to people and connect with your next collaborator.

<div align="center">
  <strong>Built with Python • Flask • Modern Frontend • GitHub Copilot Powers Development</strong>
</div>

---

## ✨ What Makes Soc Ops Special?

- 🎯 **Icebreaker Done Right** – Thoughtfully crafted questions that spark genuine connections
- 👥 **Social Networking** – Find peers with shared interests and experiences
- 🎲 **Gamified Fun** – Competitive bingo mechanics keep the energy high
- 📱 **Web-Based** – No downloads needed, works on any device
- 🤖 **Built with Copilot** – Learn how AI-assisted development works hands-on

---

## 🎯 How It Works

1. **Join the Game** – Open Soc Ops on your device
2. **Get Your Card** – Receive a personalized bingo card with fun social prompts
3. **Find Your People** – Mingle and find people who match the descriptions
4. **Get 5 in a Row** – First to complete horizontal, vertical, or diagonal lines wins
5. **Connect** – Network with other players and expand your circle

## 🚀 Quick Start

### Prerequisites
- Python 3.9+
- Your favorite code editor
- GitHub Copilot access (or try the free tier)

### Run the Game Locally

```bash
# Clone the repository
git clone https://github.com/GabrielChavesMendes/copilot-dev-days.git
cd copilot-dev-days

# Install dependencies
pip install -r requirements.txt

# Start the application
python app/main.py

# Open your browser
# Navigate to http://localhost:5000
```

Game is ready to play! 🎉

## 🏗️ Architecture

```
Soc Ops
 app/
   ├── main.py              # Flask application entry point
   ├── game_logic.py        # Game rules and scoring
   ├── game_service.py      # Game state management
   ├── models.py            # Data models
   ├── data.py              # Question data & seeds
   ├── static/              # CSS and assets
   └── templates/           # Jinja2 HTML templates
```
